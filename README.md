# 📊 Mobile Sales Dashboard (Power BI)

## 🔍 Overview

This project is an **interactive Power BI dashboard** created to analyze mobile sales data.
It provides insights into sales performance, customer behavior, and market trends.

---

## 📁 Project Files

* `mobile_sales_data.csv` → Dataset used for analysis
* `Mobile_Sales_Dashboard.pbix` → Power BI dashboard file
* `dashboard.png` → Dashboard preview image

---

## 📌 Features

* 📍 Sales analysis by city (Map view)
* 📈 Monthly sales trend
* 💳 Payment method distribution (UPI, Card, Cash)
* ⭐ Customer ratings analysis
* 📱 Top-selling mobile models
* 🏢 Brand-wise performance
* 📅 Sales by day

---

## 🛠 Tools Used

* Power BI
* CSV Dataset
* Data Visualization Techniques

## 📊 Key Insights

* UPI is the most used payment method
* iPhone SE has the highest sales
* Metro cities generate more revenue
* Weekend sales are higher than weekdays
* Apple and Samsung lead in brand sales

---

## 🚀 How to Use

1. Download the `.pbix` file
2. Open it using **Power BI Desktop**
3. Explore filters like:

   * Mobile Model
   * Brand
   * Payment Method
   * Customer Name
